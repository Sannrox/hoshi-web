# ADR 0001: Record architecture decisions

- Status: Accepted
- Date: 2026-10-11

## Context

Decisions about the web client's scope, stack and boundary with hoshi need a durable
record that contributors and agents can find.

## Decision

Record significant decisions as numbered Markdown ADRs in `docs/decisions/`, listed in
`docs/decisions/README.md`. An ADR is superseded by a new ADR, never rewritten.

## Consequences

Each significant change links to the ADR it follows or adds one.
